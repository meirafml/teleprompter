# Teleprompter

Aplicação em português, sem dependências: ajuste de velocidade, tamanho do texto, iniciar/pausar, voltar ao início e destaques de ênfase em amarelo.

Abra `index.html` no navegador. Use **Editar texto** para colar um roteiro e **Aplicar texto** para ler, ou **Abrir .txt** para importar um arquivo UTF-8.

Marque ênfases entre dois asteriscos: `Este ponto é **muito importante**.` Os asteriscos ficam ocultos durante a leitura. O arquivo é processado no navegador, sem envio a um servidor. O roteiro não é salvo ao fechar ou recarregar.

Para hospedar no GitHub Pages, selecione a branch `main` e a pasta `/ (root)` em Settings → Pages.
